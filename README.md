# dtc_aidev

Proyecto de aprendizaje y práctica de desarrollo con IA.

## Organización

- `week1/`: ejercicios y avances de la primera semana.

## Sincronizar avances

Desde la carpeta del proyecto:

```bash
git pull --rebase
git add .
git commit -m "Describe los avances"
git push
```

Revisa los cambios con `git status` y `git diff` antes de hacer commit.
