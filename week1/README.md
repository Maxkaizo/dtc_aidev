# Shared Household Chores

A small app to help a couple manage household chores. Partners choose available chores, reserve them, and mark them as done.

## Project Folder

`week1/` is the main folder for this app. App source code and supporting files will live here.

## MVP

- One household with two profiles.
- One-off and recurring chores with required due dates.
- A shared board with Available, Claimed, and Done statuses.
- Recurring chores on a fixed schedule.
- Overdue chores retain their owner.

See [plan.md](plan.md) for the full product definition, proposed decisions, and acceptance criteria.

## Status

Product scope defined; implementation has not started. The technology stack and setup instructions will be added as development progresses.
