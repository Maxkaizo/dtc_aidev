# Working Process

## Task Workflow

- Track tasks as GitHub issues and work on one issue at a time.
- Groom each task before implementation using the PM role below.
- Read the acceptance criteria before starting and review them again before closing the issue.
- Verify the result against the acceptance criteria and the technical checks in [AGENTS.md](../AGENTS.md).
- Commit regularly at meaningful milestones, following the user's instructions on when to commit and push.

## Roles

- **PM:** for issue grooming, product planning, and backlog management, read and follow [pm.md](team/pm.md). Use [task-template.md](task-template.md) when refining issues. The PM role prepares tasks and does not write application code.
- **Implementation:** follow the groomed issue and the technical conventions in [AGENTS.md](../AGENTS.md).
